```text
進入階段 2：開始部署，並先開啟測試模式。一切以階段 1 我確認過的計畫書和畫面為準，不要新增功能。

【金鑰與設定】
請讀取 .env.local，先確認它已被列入 .gitignore，
再把所有金鑰一次寫入 Cloudflare 的加密環境變數，
接著用 LINE Messaging API 自動設定 Webhook 網址並執行驗證，
最後回報每一項是否成功。過程中不要在對話中顯示任何金鑰內容。
- 需要我登入或按授權的步驟（例如 Cloudflare、GitHub 登入），請停下來告訴我怎麼做，由我自己完成。
- LINE 官方帳號後台的「自動回應訊息」如果沒有 API 可以關，請列為我要手動做的步驟，告訴我在哪裡關。

【測試模式】
- 用一個設定開關切換測試模式，關閉時不需要改程式碼。
- 測試模式下把時間縮短：
  - 按「等一下」後再提醒：10 分鐘 → 1 分鐘
  - 沒回應再提醒：15 分鐘 → 2 分鐘
  - 通知家屬群組：30 分鐘 → 3 分鐘
- 測試期間只發給我自己的 LINE 和我建立的測試群組，不發給長輩。

【驗證】
1. 先做自動模擬測試，逐項回報結果：
   - 按「吃好了」→ 記錄並回覆完成畫面
   - 按「等一下」→ 1 分鐘後再提醒；連按兩次也正確
   - 完全不回應 → 2 分鐘再提醒 → 3 分鐘通知測試群組
   - 按了「等一下」仍不吃 → 3 分鐘時照樣通知群組，不延後；且 2 分鐘時不會再發沒回應的提醒
   - 群組有人按「我來打電話」→ 通知其他家人，長輩收到「某某會打給你」
   - 長輩按圖文選單「打給家人」→ 不撥電話，家屬群組收到「媽媽找你」，長輩收到「已通知家人」；5 分鐘內再按，群組不會再收到；群組有人按「我來打電話」→ 通知其他家人，長輩收到「某某會打給你」
   - 長輩傳文字、貼圖、語音 → AI 判讀後回覆，不出現錯誤訊息
   - 問用藥劑量或要不要補吃 → 只回「請依醫師或藥師指示」
2. 列出一份讓我用手機親手測試的步驟清單，每一步寫清楚「我要做什麼、應該看到什麼」。
3. 程式推送到 GitHub 私人儲存庫，commit 訊息用中文。

完成後先停下來等我確認：不要關閉測試模式，也不要邀請長輩加好友。
過程中請用淺顯的語言說明。
```
