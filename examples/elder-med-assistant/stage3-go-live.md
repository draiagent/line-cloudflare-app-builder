# 階段 3 上線提示詞（分兩段）

---

## 3-1 上線當天（直接貼給 Claude Code）

> 使用時機：階段 2 的自動模擬測試全部通過，而且你已經照手機測試清單親手測過一遍。
> 當天請和長輩、家人在一起，需要用到長輩的手機。

```text
進入階段 3-1：正式上線。一切以階段 1、2 我確認過的內容為準，不要新增功能。

【我和家人要親手做的事】
請先列出清單並停下來等我，每一步告訴我「在哪裡按、做完會看到什麼」：
- 在長輩的手機上加官方帳號為 LINE 好友。
- 把 Bot 邀進真正的家屬 LINE 群組。
- 長輩和家人都知道這是什麼、同意使用（由我當面說明）。
每完成一項我會回報，你再往下做。

【綁定與切換】
1. 用加好友和加入群組時收到的事件，綁定長輩的 LINE 帳號和真正的家屬群組。
   ID 不要顯示在對話中，只回報「已綁定」或「失敗」。
2. 解除測試群組的綁定，之後家屬通知只發到真正的家屬群組。
3. 關閉測試模式，改回正式時間：
   - 按「等一下」後再提醒：10 分鐘
   - 沒回應再提醒：15 分鐘（按過「等一下」就不發）
   - 通知家屬群組：30 分鐘（從原定提醒時間起算）
4. 列出目前所有的提醒排程（時間、藥名），讓我確認正確。

【上線前的安全檢查】
- 若有使用 Cloudflare API Token，確認權限只限這個專案。
- 若 Google 帳號有開啟帳單，提醒我設定預算上限。
- 確認 .env.local 沒有進到 GitHub。

【真實 LINE 測試（必做）】
在不新增功能的前提下，告訴我怎麼安排一次真實提醒，讓我在長輩身邊觀察
（例如用子女網頁 App 暫時加一個幾分鐘後的排程，測完刪除）。
我會觀察三件事：字看得清楚嗎、知道按哪個按鈕嗎、按完知道已經完成了嗎。
測完我會回報結果。

完成後先停下來，接下來試用一週，這段期間不要改任何程式。
過程中請用淺顯的語言說明。
```

---

## 3-2 試用一週後（直接貼給 Claude Code）

> 使用時機：正式時間試用滿一週。先把下方【家人回饋】填好再貼。

```text
進入階段 3-2：試用一週後的檢討。這一步只整理和報告，不要修改程式，也不要刪除或修改任何紀錄。

【請整理這一週的紀錄】
1. 每一次提醒的結果：按「我已吃藥了」、按「等一下」幾次、有沒有通知家屬、誰按了「我來打電話」。
2. LINE 實際用掉的推播則數，和階段 1 的試算比較；照這個用量，一個月會不會超過免費額度。
3. 系統錯誤或沒有送出的訊息。
4. 長輩傳的文字、貼圖、語音，AI 怎麼判讀、怎麼回覆；特別檢查有沒有任何一次提到用藥劑量或補吃建議。

【家人回饋】
（由我填寫，例如：長輩哪裡看不懂、哪裡按錯、家人覺得通知太多或太少）

【請交付】
一份問題清單，分成「必須修」「建議改」「可以不改」三類，
每一項說明原因和影響。由我決定要不要改、何時正式上線。
過程中請用淺顯的語言說明。
```
