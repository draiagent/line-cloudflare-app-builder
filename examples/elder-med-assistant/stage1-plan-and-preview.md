# 階段 1 開工提示詞（直接貼給 Claude Code）

```text
我要打造「長輩服藥與健康回報管理助理」，本階段只做「計畫書＋畫面預覽」，先不要部署。

【使用者】
- 長輩（60歲以上，視力退化、不熟手機）：只使用 LINE，不裝任何 App。
- 子女：使用網頁 App（PWA）語音設定排程、看服藥紀錄。
- 家庭自用，不上架。

【核心流程】
1. 子女說「提醒媽媽每天早上8點、晚上7點吃降血壓藥」，AI 複述確認後建立每日排程。
2. 時間到，LINE 推送提醒給長輩，附「吃好了」「等一下」兩個大按鈕。
3. 長輩按下「吃好了」，系統記錄並回覆「記好了，媽媽好棒」。
4. 長輩按下「等一下」：10 分鐘後再提醒一次。
5. 沒有任何回應：15 分鐘後再提醒一次；30 分鐘仍沒有按「吃好了」，就通知家屬 LINE 群組，附「我來打電話」按鈕，有人按下後通知其他家人，也告訴長輩是誰會打來。按過「等一下」就不再發 15 分鐘的再提醒。
6. 「等一下」可以重複按，每次都是 10 分鐘後再提醒；但「30 分鐘通知家屬」一律從原定提醒時間起算，不會因為按了「等一下」而延後。
7. 長輩打字、傳貼圖或語音時，由 AI 判讀意思，絕不回覆錯誤訊息。
8. 長輩按圖文選單「打給家人」，不直接撥電話，而是通知家屬 LINE 群組請家人打給長輩，附「我來打電話」按鈕，有人按下後通知其他家人，也告訴長輩是誰會打來。

【長輩友善設計（最高優先）】
- LINE 訊息用 Flex Message，不用快速回覆的小按鈕。
- 每則訊息一個大圖示＋主標5字內＋整則20字內，按鈕最多兩個且要大。
- 圖示使用 png/ 資料夾（Flex Message 不支援 SVG；svg/ 只是原始檔）：
  - 02_yellow_remind.png「吃藥囉」→ 提醒、再提醒
  - 04_yellow_wait.png「等一下」→ 長輩按「等一下」後的回覆
  - 03_green_done.png「吃好了」→ 完成
  - 05_red_not_taken.png「還沒吃」→ 家屬群組通知（只發給家屬）
  - 06_blue_call.png「打電話」→ 家屬的「我來打電話」
- 顏色規則固定：紅＝警示、黃＝提醒、綠＝通過、藍＝功能按鈕。
- 紅色畫面只發給家屬群組，長輩永遠不會收到紅色畫面。
- 黃底的畫面一律用深色字。
- PWA 圖示與 manifest 已放在 public/ 資料夾，請直接使用。
- line/ 資料夾內有官方帳號大頭貼與圖文選單圖片，請在手動步驟清單中提醒我上傳大頭貼，圖文選單請用 LINE API 自動建立並設為預設。
- 圖示上已經印有文字。請在計畫書中逐一列出每個畫面的字數，「圖上的字」和「訊息文字」分開列，由我決定 20 字上限怎麼算。

【安全】
- AI 不得提供任何用藥劑量或補吃建議，一律回覆「請依醫師或藥師指示」。
- 金鑰從 .env.local 讀取，確認已列入 .gitignore，不可寫進程式碼，也不可在對話中顯示。
- 所有時間以 Asia/Taipei（UTC+8）計算。

【技術】
- Cloudflare（主機、資料庫、排程）＋ LINE Messaging API ＋ Google Gemini（使用目前可用、有免費額度的最新模型，告訴我你選了哪個）。
- 使用 Git 版本控管，建立 GitHub 私人儲存庫。

【本階段請交付】
1. 開發計畫書，包含：
   - 架構與資料表。
   - 10 分鐘、15 分鐘、30 分鐘這三種計時要用什麼方式觸發（例如排程每分鐘檢查一次資料庫），用淺顯的話說明為什麼這樣選。
   - 需要我親自操作的步驟清單，須包含：在 LINE 官方帳號後台開啟「允許加入群組」、把 Bot 邀進家屬群組，以及系統如何取得群組 ID。
   - LINE 每月推播則數試算：「回覆訊息」與「主動推播」分開計算，並說明哪些會計入免費額度。
   - Gemini 免費方案的資料使用條款：服藥紀錄屬於健康資料，請查證並告訴我免費方案送出的內容是否可能被用於改善模型，以及有哪些替代做法。只報告，不要替我決定。
2. 五個 LINE 畫面（提醒、等一下、完成、家屬通知、有人接手打電話）的預覽頁，讓我用手機打開給長輩看。
3. 完成後先停下來等我確認，不要進入部署。
過程中請用淺顯的語言說明。
```
